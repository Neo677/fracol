## 🎯 Objectif / Objective

**FR** :  
Ce projet a pour but de créer un programme graphique capable de générer et d'afficher des fractales, en utilisant la bibliothèque graphique MiniLibX. Les fractales sont des objets mathématiques auto-similaires à différentes échelles, offrant des motifs infiniment complexes et esthétiques.

**EN** :  
This project aims to create a graphical program capable of generating and displaying fractals, using the MiniLibX graphical library. Fractals are mathematical objects that are self-similar at different scales, offering infinitely complex and aesthetic patterns.

---

## 🛠️ Fonctionnalités / Features

- **FR** :
  - Génération et affichage des ensembles de Mandelbrot et de Julia.
  - Zoom infini avec la molette de la souris.
  - Différentes palettes de couleurs pour la visualisation.
  - Gestion fluide de la fenêtre graphique.
  - Fermeture propre du programme via la touche `ESC` ou le bouton de fermeture de la fenêtre.

- **EN** :
  - Generation and display of Mandelbrot and Julia sets.
  - Infinite zoom with the mouse wheel.
  - Different color palettes for visualization.
  - Smooth management of the graphical window.
  - Clean program exit via the `ESC` key or the window's close button.

🚀 Utilisation / Usage

FR :
Après compilation, exécutez le programme avec le nom de la fractale souhaitée en argument :

./fracol mandelbrot

Commandes disponibles :
	•	ESC : Quitter le programme.
	•	Molette de la souris : Zoomer/dézoomer.
	•	Flèches directionnelles : Déplacer la vue.
	•	Touches 1 à 6 : Changer de fractale.
	•	Touches Q à Y : Modifier la palette de couleurs.

EN :
After compilation, run the program with the desired fractal name as an argument:

./fracol mandelbrot

Available controls:
	•	ESC: Exit the program.
	•	Mouse wheel: Zoom in/out.
	•	Arrow keys: Move the view.
	•	Keys 1 to 6: Change fractal.
	•	Keys Q to Y: Change color palette.
